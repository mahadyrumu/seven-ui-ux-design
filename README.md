# Seven UI/UX Design Recreation Project

This project is a high-fidelity, pixel-accurate visual recreation of 7 distinct UI/UX reference designs, built using Next.js 15, Tailwind CSS v4, and Framer Motion. 

## 🚀 Live Deployment
**Production URL:** [https://seven-ui-ux-design.vercel.app/](https://seven-ui-ux-design.vercel.app/)

## 📄 Implemented Screens
1. **Ride-Share Trip Details** (`/ride-trip-details`)
2. **Art Showcase Landing** (`/art-showcase`)
3. **Travel App Landing** (`/travel-landing`)
4. **Finance Dashboard Landing** (`/finance-landing`)
5. **Real Estate Investment Landing** (`/real-estate-landing`)
6. **Pricing Plans** (`/pricing-plans`)
7. **Developer Portfolio Landing** (`/developer-portfolio`)

## 🛠️ Technology Stack
* Next.js 15 (App Router)
* React 19
* TypeScript
* Tailwind CSS v4
* Framer Motion
* Lucide Icons

*Developed with strict adherence to visual QA guidelines and responsive design principles.*
